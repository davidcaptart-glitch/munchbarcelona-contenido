# Contenidos de la web de Munch Barcelona

Este repositorio guarda los textos y las fotos que se pueden editar en la web:
**Munchs**, **Normas**, **Concurso** y **Equipo**.

**No hace falta tocarlo a mano.** Se edita desde el panel de la web (`/admin`), que guarda aquí cada cambio.
La web lo lee cada vez que alguien la visita, así que lo que se guarda en el panel se ve en unos minutos.

- `munchs.json`, `normas.json`, `concurso.json`, `equipo.json`: textos en castellano (`es`) y catalán (`ca`).
- `imagenes/`: logos y fotos.

Cada cambio queda en el historial (*Commits*), así que cualquier error se puede deshacer.

Tiene que ser **público**: si fuera privado, la web no podría leerlo.
El código de la web está en `barcelonamunch-collab/munchbarcelona` (ver `GUIA-PANEL.md`).
